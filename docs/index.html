Üç hareket, sıfır uğraş

Ekran donar, alanı seçersin, metin tanınır ve panoya düşer. Başka pencere, başka adım yok.

  1. 01

    Kısayola bas

    Super + Shift + T ile Wayfrost’u çağır. Kurulum bu kısayolu GNOME’a tanımlar.

  2. 02

    Alanı seç

    Okumak istediğin bölgeyi çerçevele. Ters seçim ve boş seçim güvenli şekilde ele alınır.

  3. 03

    Yapıştır

    Tanınan metin panoya yazılır. Terminalde ya da düzenleyicide doğrudan yapıştır.

Bir komutla kur

Depoyu klonla, betiği çalıştır. Bağımlılıklar dağıtımına göre kurulur, ikili derlenir, kısayol tanımlanır.

git clone https://github.com/Lowell137/wayfrost.git
cd wayfrost
chmod +x install.sh
./install.sh
Arch / Manjaro / CachyOS bağımlılıkları 
sudo pacman -S --needed --noconfirm base-devel rust cargo gtk4 libadwaita tesseract tesseract-data-tur tesseract-data-eng git openssl pkgconf
Debian / Ubuntu / Pop!_OS / Mint bağımlılıkları 
sudo apt update && sudo apt install -y build-essential cargo rustc libgtk-4-dev libadwaita-1-dev tesseract-ocr tesseract-ocr-tur tesseract-ocr-eng git libssl-dev pkg-config
Fedora / RHEL / CentOS bağımlılıkları 
sudo dnf install -y gcc-c++ cargo rust gtk4-devel libadwaita-devel tesseract tesseract-langpack-tur tesseract-langpack-eng git openssl-devel pkg-config
İkili ~/.local/bin/wayfrost
GNOME uzantısı wayfrost@lowell

Not: Uzantı hemen görünmezse GNOME Shell’i yeniden başlat ya da oturumu kapatıp aç. Çıkış için seçim ekranında ESC yeterli; arkada pencere bırakmaz.
